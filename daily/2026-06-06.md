## 学习路径（Agentic Commerce）

Agentic Commerce 讨论的是：当 Agent 能代表用户发现商品、调用 API、比较报价、发起付款和验收结果时，商业流程应该如何被重新设计。

**知识节点**：Agents Purchasing APIs / Payment Intent / Budget Control / Proof of Task Completion / On-chain Receipt / Escrow Flow

- [ ] **最小路径（30 min）**：通读 Agentic Commerce 章节 → 掌握 6 个知识节点 → 回答：你的 Agent 帮用户买 API 服务时，Budget Control 和 Payment Intent 的关系是什么？

- [ ] **推荐路径（60 min）**：最小路径 + 用自然语言设计一个 **Payment Intent 模板**（包含预算、资产、可接受服务方、质量要求、退款条件、有效期）→ 写一段对比：Proof of Task Completion vs On-chain Receipt 有什么区别，各在什么场景用

- [ ] **挑战路径（90 min）**：推荐路径 + 在 `experiments/agentic-commerce/` 下创建一个 **Payment Intent 模板.md** → 选择一个真实场景（如 Agent 帮你买一个 AI 模型推理 API），填写完整的 Payment Intent → 写一篇 300 字中文 Thread：Agentic Commerce 不是让 Agent 替你花钱，是把花钱变成可编程协议
